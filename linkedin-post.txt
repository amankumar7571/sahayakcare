Elderly care in India runs on memory and missed calls. A grandmother forgets her BP tablet, nobody knows until the next hospital visit — and by then it's a crisis, not a reminder.

I built SahayakCare for the Catalyst hackathon's problem statement: an Elderly Care & Medication Management Platform. One shared profile for the elderly person, their family and caretakers — so everyone sees the same medicines, the same appointments, the same truth.

What it does: a passcode-protected care profile with medication schedules you can add and edit, adherence tracking with a live 7-day score, day streak and a "most-missed slot" insight, doctor appointments with the next visit always in view, a care circle where new members need the elderly person's approval, a vitals log, and a reminders engine that flags missed doses and appointments coming up — and drafts the email to the primary caretaker in one tap.

What makes it different: it's built for the 74-year-old, not the 24-year-old developer. Large-text mode, English/Hindi toggle, big touch targets. No account, no server, nothing leaves the phone — all data stays in the browser, and a share link opens the same profile on a family member's device.

Built as a single self-contained HTML file — vanilla JavaScript + Tailwind, data in localStorage — by prompting Gemini, then hand-verified line by line. 117 automated checks pass on the code.
